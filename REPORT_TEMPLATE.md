# Project Report Template

## 1. Core Algorithm: Design and Implementation

- Explain the main algorithm and how it meets this phase's requirements.
- Point to the main source files or functions. Explain important design choices; avoid pasting large amounts of code.

## 2. Problems and Solutions

For each significant problem, describe:

- **Problem**: What went wrong? Include a failing case, error, or measurement when available.
- **Cause and solution**: What caused it, and what did you change?
- **Verification**: How did you check that the change worked?

## 3. Experimental Results and Analysis

**Setup**: State the machine, input data, commands or parameters, thread counts, and how execution time was measured. Use the same setup for results you compare.

**Correctness**: Describe the tests you ran and the expected and observed results.

**Performance**: Report the results requested in the phase instructions. Include the baseline and relevant comparisons in a table or figure. For example:

| Input / workload | Version / configuration | Threads | Time | Speedup vs. baseline |

**Analysis**: Explain what the results show, including unexpected behavior. Connect your explanation to measurements or observations, and note any limits of the experiment.

## 4. Discussion

Answer each Discussion question in the phase instructions. Copy or number each question so your answer is easy to match to it. Support answers with your design, tests, or results where relevant.
